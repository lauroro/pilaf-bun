
# pilaf-bun

A small experiment using Bun as a CLI tool to manage a Base16-based ricing setup on Linux.

----------

## Overview
**pilaf-bun** started from my curiosity about [Bun](https://bun.sh/) as an alternative to Node.  
I wanted to create a newer implementation of my previous ricing tool, [pyrice](https://codeberg.org/roro/pyrice), so I decided to try building a simple CLI tool with it.

Although Bun was a much nicer experience compared to Node, I eventually got a bit stressed working on the project and decided not to continue developing it further. There are other languages and tools that I find more interesting to explore, and that I’m more excited to learn and experiment with.

This repository remains as a small experiment and a snapshot of that exploration.

----------

## Status

This repository is archived and no longer maintained.

I'm leaving it here mostly for reference and for the random stuff I experimented with while building it.
